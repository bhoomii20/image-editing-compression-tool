# 🖼️ Advanced Image Processing & Compression Tool

An interactive web-based tool built for **Image Processing and Vision (IPV)** course that combines **image editing** with **JPEG compression** and real-time visual analysis.

## ✨ Features

### Editing Tools
- **Resize** – Custom width × height
- **Crop** – Interactive crop with preview
- **Brightness & Contrast** adjustment
- **Grayscale** with intensity control
- **Background Removal** (basic)

### Compression
- **Quality Mode** – Manual JPEG quality slider (10% - 100%)
- **Target Size Mode** – Automatically finds best quality to match desired file size
- Real-time **PSNR** calculation
- **Difference Map** (Error Heatmap) to visualize quality loss
- **RGB Histogram** comparison

### Other Features
- Single & **Batch Processing**
- Download individual images or **all as ZIP**
- Clean, responsive UI using Streamlit

## 🛠️ Technologies Used

- **Python** 
- **Streamlit** – Web Interface
- **OpenCV** – Image processing & analysis
- **Pillow (PIL)** – JPEG compression
- **NumPy** – Pixel-level operations
- **Matplotlib** – Histograms
- **scikit-image** – PSNR calculation
